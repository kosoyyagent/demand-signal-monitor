# Бот-мониторинг сигналов спроса (мягкие игрушки / мерч)

Следит за тремя источниками и шлёт уведомления в Telegram при появлении новых страниц/постов. Без дублей (база `seen.db`).

## Источники
1. **Яндекс-выдача** — новые страницы за последние 24 часа по заданным фразам (фильтр `within=77`). Уведомление содержит заголовок и ссылку.
2. **Публичные TG-каналы** — посты, содержащие ключевые слова (`игрушка`, `мерч`, `сувенир`, `подарок`).
3. **ТПП-площадка** — рубрика «Мягкие игрушки» (URL задаётся в `config.json`).

## Установка
```
pip install playwright
playwright install chromium   # не нужно, если используется режим chrome-cdp
```
Скопировать `config.example.json` → `config.json`, вписать токен бота и chat_id.

## Запуск
```
python monitor.py once    # один прогон (проверка)
python monitor.py loop    # цикл каждые 30 минут
```

## Автозапуск (Windows)
```
schtasks /create /tn "DemandMonitor" /tr "python C:\path\monitor.py loop" /sc onstart /rl highest
```
или планировщик задач — «При входе в систему».

## Уведомления
Если токен бота не задан — пишет в `notifications.log` и консоль.

## Отказоустойчивость
- Капча Яндекса: автоматически переключается на чтение через локальный Chrome (CDP:9222) — без прокси и без сторонних сервисов.
- Смена вёрстки сайтов: парсеры изолированы, ошибка одного источника не роняет остальные (cycle error в лог).
- Дедупликация: URL → SQLite, повторные уведомления не отправляются.
